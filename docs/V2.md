# v2 and later

Deferred on purpose, so they don't creep into v1. Each item notes where it was decided.

- **Cloud semantic validation.** Propose a standalone `validate-workbook` tool to
  [tableau-mcp](https://github.com/tableau/tableau-mcp), wrapping the REST **Validate Workbook** endpoint
  (Tableau Cloud June 2026 / Server 2026.2). Today tableau-mcp only validates inside `publish-workbook`.
  We could run it in the local tableau-mcp clone while the PR is open. Until then, the Desktop check is
  the load test. *(Grilling, 2026-09-29.)*
- **Sankey charts.** Built in Tableau as a viz extension (`mark class='VizExtension'`; 7 sheets in 3
  local workbooks use one). Tableau's plugin has `sankey-viz-extension.tbm` and
  `flow__sankey__trace-volume-through-multi-stage-paths.tbm` to learn from. *(Grilling, 2026-09-29.)*
- **`twb-build-from-spec`.** A batch tool that takes a whole dashboard spec (JSON/YAML) and calls the same
  add-sheet / add-chart / add-dashboard operations as the step-by-step tools. *(Grilling, 2026-09-29:
  "shared tools, spec later".)*
- **Desktop Agent API.** When Desktop ships the Agent API that tableau-mcp's Desktop mode uses
  (`~/.tableau/agent-manifest.json`, `apply-workbook`), use it as the load test instead of reading
  Desktop's log. *(Research, 2026-09-29.)*
